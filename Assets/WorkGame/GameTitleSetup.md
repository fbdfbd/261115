# 타이틀

`01_Title`에 이미 배치했습니다. 씬을 열어 실행하면 됩니다.
기존 카메라·조명은 유지하고 Canvas_Title, EventSystem, 메뉴·옵션·슬롯·모음집 프리팹을 배치했습니다.

## 구성

- GameTitle: 화면 왼쪽의 새로하기 / 이어하기 / 모음집 / 설정 / 종료.
- GameOptions: 기존 옵션 프리팹 재사용. 타이틀에서는 타이틀 복귀 버튼을 숨깁니다.
- GameSaveSlots: 기존 슬롯 프리팹 재사용. Work Root는 비워 두어 타이틀의 불러오기 경로로 동작합니다.
- GameCollection: 달이의 성장 기록. 5×5 목록과 엔딩 상세/조건을 표시합니다.

GameTitleRoot의 옵션·슬롯 참조와 각 버튼 이벤트는 연결했습니다. 별도 OnClick 등록은 필요 없습니다.

## 동작

- 새로하기: 02_Game으로 이동합니다. 구매한 업무 스킬은 확정된 저장 기록에서 계승하고 현금·숙련포인트·가구·달이 상태는 초기화합니다. 수동 슬롯·읽음 기록은 유지합니다.
- 이어하기: 저장된 슬롯이 있으면 활성화됩니다. 슬롯 패널에서 선택하면 해당 시작 체크포인트로 게임에 진입합니다.
- 모음집: GameCollectionRoot에 연결했습니다. 미획득 엔딩도 상세 조건을 볼 수 있습니다. On Collection Requested는 추가 연출용 이벤트입니다.
- 설정: 기존 옵션창을 엽니다. 닫으면 타이틀 메뉴로 돌아갑니다.
- 종료: PC는 앱 종료, 에디터는 Play 종료입니다. 웹에서는 종료 버튼을 비활성화합니다.

## 편집과 툴

`Work Game > UI > Game Title Tool`에서 프리팹을 생성하고 01_Title에 배치할 수 있습니다.
이미 메뉴가 배치된 경우 기존 메뉴를 선택하며 중복 생성하지 않습니다.
현재 생성한 GameTitle.prefab과 씬 연결을 그대로 사용하면 됩니다.

- LeftMenu RectTransform: 왼쪽 가운데 앵커/피벗, 440×560, 왼쪽 여백 96.
- LeftMenu Vertical Layout Group: 버튼 간격 16, 패딩 24. 가로 폭은 부모를 채우며 버튼 높이는 72입니다.
- 각 버튼 Label: 기본 글자 크기 34. 폰트·배경·폭·간격은 프리팹에서 수정할 수 있습니다.
- Canvas_Title: Screen Space Overlay, 기준 해상도 1920×1080, Match 0.5.
- 별도 타이틀 배경 이미지는 만들지 않았습니다. 기존 카메라 배경이 보입니다.

빌드 목록은 01_Title → 02_Game 순서로 활성화했습니다. 빌드 실행 시 타이틀에서 시작합니다.
현재 에디터에서 타이틀 흐름을 보려면 01_Title만 단독으로 열고 실행하세요.
배치 툴도 타이틀을 단독으로 엽니다. 업무 씬을 함께 열고 실행하면 업무 Root가 새 게임을 시작할 수 있으므로 함께 실행하지 않습니다.

컴파일·플레이·테스트 실행은 하지 않았습니다. 프리팹 및 씬의 ID·참조·계층을 파일에서 확인했습니다.
