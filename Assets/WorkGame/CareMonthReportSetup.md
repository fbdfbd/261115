# 달이 육성 결과창

## 생성과 씬 연결

1. `Work Game > UI > Care Month Report Tool`을 엽니다.
2. 기본 1300×800 크기로 육성 결과 프리팹을 생성합니다.
3. 육성 화면 Canvas 아래 배치합니다. 프리팹과 부모 Canvas의 GameObject 체크는 켜 둡니다. 숨김은 CanvasGroup으로 처리합니다.
4. WorkRoot의 `Care Month Report View`에 씬의 CareMonthReportView를 연결합니다.

화면 클릭은 생성기와 일반 C# Presenter가 자동 연결합니다. 별도 확인 버튼이나 수동 OnClick 연결은 필요 없습니다.
업무 중에만 보이는 Work Groups 아래에는 넣지 마세요. 육성 쪽 After Work Groups 아래 또는 별도 활성 Canvas에 배치합니다.

## 실제 흐름

4칸 편성 → 편성창 닫기 → 메인의 다음 달 클릭 → 수업료 차감·스텟 적용 → 1주차 → 2주차 → 3주차 → 4주차 결과 → 약속 대화 또는 다음 달 업무입니다.
12월 결과 확인 후에는 엔딩으로 이어집니다. 결과를 보여줄 때 수업료·스텟을 다시 적용하지 않습니다.

## 표시 내용

- 중앙에 가로 4 : 세로 3 이미지 하나를 표시합니다.
- 아래에는 수업 중 무엇을 했는지 달이의 한마디를 한 글자씩 표시합니다. 기본 간격은 글자당 0.035초입니다.
- 주요 스텟 4개는 HUD처럼 세로로 표시합니다. 기본 폭은 현재 씬 HUD와 같은 370, 높이는 기본 페이지에서 252입니다.
- 각 줄은 `이름 · 등급 · 슬라이더(안에 수치와 증가량)`입니다. 막대와 숫자가 해당 주 시작 값에서 해당 주 결과값까지 올라갑니다.
- 막대는 등급 안의 진행도입니다. 기본 C 0~99, B 100~199, A 200~349이며 경계를 넘으면 새 등급의 0부터 채웁니다. S는 가득 표시합니다.
- 숫자와 증가량은 실제 누적 수치를 유지합니다. 등급 표시는 막대 연출이 해당 경계를 지날 때 함께 바뀝니다.
- 수업·시너지·장착 가구 보정과 세부 스텟 최대치가 반영된 실제 적용 결과를 사용합니다.
- 편성한 순서 그대로 각 주 수업의 이미지와 대사를 보여줍니다. 같은 수업을 반복해도 주차를 생략하지 않습니다.
- 홈스쿨링·휴식도 해당 주에 무료 수업용 한마디와 기본 이미지로 표시합니다.
- 주차별 실제 증가량은 월 결과에 저장됩니다. 누적 성장량의 차이로 나누어 가구 보정의 소수점 버림·최대치까지 월간 합계와 일치합니다.
- 시너지 증가는 필요한 수업을 모두 들은 주차에 한 번 반영됩니다. 결과창은 저장된 결과만 읽으므로 수업료·스텟이 중복 적용되지 않습니다.

## 이미지와 대사 데이터

각 CareLessonSO의 Result Image / Result Line을 수정합니다. Result Line은 수업 32개에 한 줄씩 작성해 두었습니다.
이미지가 없으면 CareMonthReportView의 Default Picture를 사용합니다. Picture Image에 직접 지정한 초기 Sprite도 기본 이미지로 사용합니다.
결과 이미지가 모두 없으면 이미지 틀만 표시합니다. 임시 그림을 하나 넣어 모든 수업에 공통 사용해도 됩니다.
CareContent.json의 resultLine에도 같은 대사를 추가했습니다. 데이터 재생성 시 ResultImage는 기존 SO 값을 유지합니다.

## 크기와 연출 조정

- Page: 전체 패널 크기.
- Page/ImageArea: 이미지 최대 영역. PictureFrame의 Aspect Ratio Fitter가 4:3을 유지합니다.
- Page/Feedback/Line: 한 줄 피드백. 기준 28, 자동 줄바꿈 없이 긴 글은 말줄임합니다.
- Page/Stats: Vertical Layout Group의 Spacing으로 줄 간격을 조절합니다. RectTransform의 Width로 폭을 바꿉니다.
- 각 스텟 줄: Horizontal Layout Group의 Spacing / Padding으로 내부 간격을 조절합니다.
- 각 줄의 Slider에만 Layout Element의 Flexible Width 1을 두어 남은 폭을 채웁니다.
- Name / Grade / Slider/Value의 폰트 크기를 수정합니다. Value는 반드시 막대 앞에 표시되는 자식으로 둡니다.
- Page/ContinueHint: 화면 클릭 안내. 확인 버튼은 없습니다. 루트의 CareDialogueClickArea가 전체 화면 클릭을 받습니다.

이미지 → 한 글자씩 한마디 → 스텟 4줄 순으로 나타납니다. 스텟은 94%에서 원래 크기로 커지며 막대와 숫자가 증가합니다.
배경과 패널 전체의 페이드·On Open은 처음 진입할 때만 실행합니다. 다음 주차에서는 배경을 그대로 두고 이미지·글자·스텟만 연출합니다.
출력 중 화면을 누르면 글자·막대·숫자 연출을 끝까지 표시합니다. 같은 클릭으로 다음 달까지 넘어가지 않습니다.
모든 내용이 표시된 상태에서 다시 클릭하면 다음 주차로 갑니다. 4주차에서만 약속 대화 또는 다음 달로 진행합니다.
연출을 자연스럽게 끝까지 봤다면 한 번의 클릭으로 해당 주차를 넘깁니다. 패널 하나를 계속 재사용하므로 추가 프리팹·씬 연결은 필요 없습니다.
View의 Open Seconds / Picture Seconds / Letter Seconds / Stat Gap / Stat Seconds에서 속도를 조절합니다.
줄의 Up Color / Down Color / Normal Color에서 증감·등급 색을 조절합니다. On Open / On Ready는 효과음 등 추가 연출 연결용입니다.
창을 숨기면 Tween을 종료하며, 별도 Update는 없습니다. 숫자 문자열은 표시할 정수가 바뀔 때만 갱신합니다.

기존 CareMonthReport.prefab에도 같은 구조를 적용했습니다. 루트 View와 스텟 View의 기존 ID는 유지했으므로 재생성하지 않아도 됩니다.
씬 수정·컴파일·플레이·테스트는 실행하지 않았습니다.
