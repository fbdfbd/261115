# 저장·불러오기 슬롯 패널

## 생성과 연결

1. `Work Game > UI > Game Save Slots Tool`에서 프리팹을 생성합니다. 기본 크기는 중앙 1000×800입니다.
2. Canvas에 배치합니다. 루트는 활성화 상태로 두며 실행 시 CanvasGroup으로 숨깁니다.
3. 타이틀 버튼이 생기면 `GameSaveSlotsRoot > Open Buttons`에 이어하기 버튼을 넣습니다.
   또는 버튼 OnClick에서 `GameSaveSlotsRoot.OpenLoad()`를 호출합니다. 둘 중 하나만 연결합니다.

게임의 정지 메뉴에서는 GamePauseRoot의 Save Slots Root 필드에 이 Root를 연결합니다.
현재 `02_Game`에는 이미 연결했으므로 기존 프리팹을 다시 생성할 필요가 없습니다.

타이틀에서는 **Work Root를 비워 둡니다**. 슬롯을 누르면 해당 불러오기 요청을 전달하고 `02_Game` 씬으로 이동합니다.
기존 WorkRoot는 이 요청을 먼저 소비하므로 새 게임으로 자동 슬롯을 덮어쓰지 않습니다.
타이틀 UI 자체는 아직 만들지 않았습니다.

게임 씬에서 시험하려면 선택 사항인 Work Root 필드에 현재 WorkRoot를 넣습니다.
이 경우 씬을 다시 열지 않고 같은 Root에서 해당 슬롯을 복원합니다. 창을 열면 일시 정지하며 취소하면 이전 상태로 돌아갑니다.
`OpenSave()`는 저장 모드, `OpenLoad()`는 불러오기 모드입니다. 제목과 슬롯 선택 가능 상태를 자동 변경합니다.

## 표시

자동 저장 1개 + 수동 저장 4개를 세로로 표시합니다.

```
자동 저장   3월   지식   체력   감성   사교
                   120     70     85     45
슬롯 1      1월   ...
슬롯 2      비어 있음
슬롯 3      비어 있음
슬롯 4      비어 있음
```

월과 대표 스탯의 **저장 당시 값**만 표시합니다. 세부 스탯, 저장 시각, 현금, 친밀도는 표시하지 않습니다.
지식·체력·감성·사교는 저장된 세부 스탯 3개씩을 합산합니다.
불러오기 모드에서는 빈 슬롯/잘못된 파일의 선택을 막고, 유효한 슬롯 클릭 시 바로 불러옵니다.
저장 모드에서는 자동 슬롯을 제외한 수동 4개를 선택할 수 있습니다. 빈 칸에는 새로 저장하고 기존 파일은 덮어씁니다.
저장 성공 메시지와 갱신된 월·대표 스탯을 표시합니다. 저장 중 오류가 나면 패널을 유지하고 오류를 표시합니다.
닫기와 바깥 배경은 패널을 닫습니다.

`Page` 크기는 중앙 앵커/피벗으로 조절합니다. `Page/Slots`의 Vertical Layout Group에서 간격을,
각 슬롯 RectTransform Height에서 높이를 조절합니다. 슬롯에는 LayoutElement를 추가하지 않았습니다.
View, Root, 카드 5개와 각 텍스트 참조는 생성 툴이 연결합니다.

## 저장 시스템 변경

기존 `Auto`, `Manual1`~`Manual3` ID/키를 유지하고 `Manual4`만 뒤에 추가했습니다.
수동 저장 API는 이제 `workRoot.SaveManual(1~4)`, 불러오기는 `LoadManual(1~4)`입니다.
저장 모드는 현재 진행 상태를 새로 캡처하지 않고 현재 루프의 시작 체크포인트를 수동 슬롯에 복사합니다.
덮어쓰기는 슬롯 클릭 시 즉시 진행합니다.
타이틀에서 C# 코드로 직접 불러오기 요청을 하려면 `WorkStartRequest.Load(SaveSlot.Manual4)`도 사용할 수 있습니다.

슬롯 확장, 저장된 대표 스탯 미리보기, 빈 슬롯/잘못된 파일 구분, 업무·육성 정지 중 저장 후 복원 테스트를 추가했습니다.
컴파일·플레이·테스트 실행은 하지 않았습니다.
