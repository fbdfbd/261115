- 15개 업무·675개 상황: SO ↔ CSV ↔ JSON 불일치 0건.

- H/V/Dots/Grade 4개 프리팹의 후보 및 선택 버튼이 모두 A/B/C 순서. 씬에 이를 바꾸는 명시적 참조/색상 오버라이드는 발견되지 않음.

- 15개 상황의 강조 단어를 수정. Rule·상황 제목·비교 항목·수치·단위는 이번 점검에서 변경하지 않음.

- 검증은 저장된 데이터와 코드/프리팹 연결 및 독립 .NET 실행 기준. Unity Game View에서 동일 증상을 재현하거나 최종 렌더링을 육안 확인한 결과는 아님.
