# 이달의 성과 연결

1. `Work Game > UI > Month Report Prefab Tool`에서 폰트와 문서 크기를 지정하고 프리팹을 생성합니다.
2. Canvas 아래에 배치하고 루트 GameObject는 활성 상태로 둡니다. View가 CanvasGroup으로 숨깁니다.
3. 정산서는 Work Groups 안에 둘 수 있습니다. 퇴근 후 정산서를 확인할 때까지 업무 그룹을 유지합니다. After Work Groups에는 넣지 않습니다.
4. WorkFlowRoot의 Month Report에 씬에 배치한 WorkMonthReportView를 연결합니다.
5. 기존 Next Month Button 연결은 유지합니다. 정산서 확인 버튼은 생성기가 연결하므로 OnClick을 추가하지 않습니다.
6. WorkConfig > Settings > Monthly Salary에서 고정 월급을 조절합니다. 임시 기본값은 1,000입니다.

퇴근 → 정산서 → 다음(확인) → 퇴근 후 화면 → 다음 달 버튼 → 다음 달 시작 순서입니다.
12월에는 확인 후 WorkFlowRoot의 On Run Finished 이벤트를 호출합니다. 엔딩 화면은 그 이벤트에 연결합니다.
정산서를 연결하지 않은 기존 씬은 기존처럼 바로 다음 달로 진행합니다.

## 연출

WorkMonthReportView의 Open / Points / Salary / Close Seconds와 두 Delay로 단계 시간을 조절합니다.
On Open → On Points → On Salary → On Ready → On Close 이벤트에 소리나 다른 연출을 연결할 수 있습니다.
추가 연출이 끝난 뒤 확인 버튼을 켜려면 해당 단계 Seconds / Delay에 그 시간도 반영합니다.
내장 DOTween 시퀀스는 일시정지와 관계없이 실제 시간으로 진행하며, 종료·재시작 시 자신의 트윈만 정리합니다.

포인트와 급여의 각 행은 위에서부터 순서대로 페이드인하며 원래 크기의 90%에서 100%로 커집니다.
Row Start Scale(기본 0.9), Row Seconds(0.22초), Row Gap(시작 간격 0.1초), Row Ease로 조절합니다.
Point Rows / Salary Rows 목록 순서가 등장 순서입니다. 비어 있으면 기존 텍스트의 부모 행을 사용하므로 이전 프리팹도 재생성할 필요가 없습니다.
새 프리팹은 생성기가 행 CanvasGroup과 목록까지 연결합니다. 비활성 보너스 행은 건너뛰고 모든 행의 등장 후 확인 버튼을 활성화합니다.

## 정산 데이터

MonthResult는 퇴근 순간의 스냅샷입니다. 재화는 퇴근 시 한 번만 지급하며, 정산서를 열 때는 다시 지급하지 않습니다.
서류 처리는 실제 획득한 숙련 포인트의 합, 실수는 실제 차감량의 합입니다.
추가 포인트는 칼퇴요령 보너스와 그 달에 적용된 남은 시간 비례 퍼센트입니다.
숙련 포인트 합계는 서류 처리 - 실수 + 추가 포인트이며, 강화 구매 지출은 포함하지 않습니다.
급여는 숙련 포인트와 별도로 Run.Money에 누적됩니다. 분기 외의 달에는 보너스 행이 숨겨집니다.
보유 현금은 해당 월의 급여 지급 직후 잔액을 MonthResult.MoneyBalance에 저장해 표시합니다.
기존 프리팹에는 급여 구역의 합계 아래에 보유 현금 행을 복제해서 만들고, 숫자 TMP를 WorkMonthReportView의 Cash Text에 연결합니다.
부모 행에는 CanvasGroup을 두면 됩니다. 없으면 처음 열 때 자동으로 붙이며, 보유 현금 행도 마지막에 순서대로 등장합니다.
새로 생성하는 프리팹은 이 행과 필드가 자동 연결됩니다. 행 추가로 공간이 부족하면 문서 높이를 늘려 주세요.

3·6·9·12월에는 해당 분기 정답률 90% 이상 S, 80% 이상 A, 나머지 B로 평가합니다.
미처리 서류도 분모에 포함하며 오답으로 취급합니다. 업무가 없는 분기의 보너스는 0입니다.
보너스는 고정 월급의 S 300% / A 200% / B 150%를 월급과 별도로 지급합니다.
예: 월급 1,000이면 S 평가 월에는 월급 1,000 + 보너스 3,000 = 합계 4,000입니다.
WorkConfig의 S / A Percent와 S / A / B Bonus Percent에서 기준과 배율을 조절합니다.
소수점 이하 금액은 버립니다.

자동 테스트와 컴파일은 실행하지 않았습니다.
